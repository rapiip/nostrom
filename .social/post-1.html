Autonomous agent treasury

Three ways it ends.

An agent needs a hot key to spend its budget. That key lives in a running process, on a server, signing unattended — the least protected thing in the system.

NOSTROM
01

Process dies

Nothing signs again. The balance simply sits there, unreachable.

02

Key is lost

The funds are mathematically unreachable. There is no recovery path.

03

Agent compromised

The attacker holds the key. You learn it from the balance, not an alert.

On-chain, all three look identical.
Nothing distinguishes them. Nothing reacts.
